# 📄 Personal Portfolio / Resume Website

This repository contains my personal resume website, built using the excellent open-source theme
👉 [sproogen/modern-resume-theme](https://github.com/sproogen/modern-resume-theme)

The purpose of this project is to present my professional experience, skills, projects, and background in a clean, modern, and responsive format. The site is fully static and hosted through GitHub Pages.

## 🚀 Purpose

The goal of this repository is to:
- Provide a central place where recruiters, collaborators, and hiring managers can quickly learn about my technical background and career.
- Showcase my professional experience, core skills, and education in a polished, web-based format.
- Serve as a lightweight, easy-to-maintain version of my CV, automatically deployed and hosted online.
- Explore and customize the modern-resume-theme to suit my personal branding and layout preferences.
